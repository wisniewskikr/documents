DESCRIPTION
-----------

An Office add-in is a plugin that integrates with Microsoft Office applications to extend their functionality, automate tasks, or connect them with other services.

INSTALLATION
------------

Installation commands:
* npm install -g yo generator-office
* yo office

Sometimes you have to change version of npm. You can do it with:
* nvm install 20
* nvm use 20

USAGE
-----

Usage:
* npm start
* In Excel: Home -> Add-ins -> Developer Add-ins
