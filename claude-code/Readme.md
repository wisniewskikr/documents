# Claude Code – README

## Description
Claude Code is a command-line (terminal) application that allows you to generate code, debug projects, build websites, create applications, and perform many other development tasks.

---

## Usage

To use it you just have to type following command in your command line tool: `claude`

----

## Shortcuts

| Shortcut | Action |
|--------|--------|
| `?` | Show shortcuts |
| `Esc` x2 | Clear the prompt |
| `Alt + Enter` | Insert a new line |
| `Ctrl + O` | Open logs |
| `Ctrl + B` | Run in background |

---

## Models

Claude Code provides several AI models:

- **Opus** – Most powerful but the most expensive
- **Sonnet** – Balanced option
- **Haiku** – Basic and lightweight model

---

## Modes

Switch modes using `Alt + M`.

Available modes:

- **Ask Mode** – General questions and explanations
- **Code Mode** – Focused on generating and modifying code
- **Planning Mode** – For planning projects or tasks

---

## Instructions (Commands)

| Command | Description |
|-------|-------------|
| `/help` | Show Claude help |
| `/exit` | Exit Claude (the session is lost) |
| `/init` | Creates a `claude.md` file for the project to store context |
| `/task` | Shows background tasks/servers. Press `k` (Kill) to stop a task |
| `/agents` | Create tasks or delegate tasks to agents |
| `/msp` | Connect to an external service (e.g., Google) |
| `/skills` | Create a reusable skill that can be called later |
| `/clear` | Clear the current session |

---

## CLAUDE.MD

The `claude.md` file stores project context and history. This allows Claude Code to remember previous project information.

Create it with: `\init`
