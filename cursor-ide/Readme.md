# Cursor – Overview and Shortcuts

## DESCRIPTION

Cursor is a code editor with built-in artificial intelligence, designed primarily to help write and edit programs faster.

**In short:**

* works similarly to Visual Studio Code
* has built-in AI that helps write code
* can generate program fragments, fix errors, and explain code

**What it is used for:**

* automatic code completion
* creating functions based on a description
* analyzing the entire project
* quickly fixing bugs

👉 **In short:** Cursor = programming editor + AI coding assistant.

---

# KEYBOARD SHORTCUTS

## AI – Most Important Cursor Shortcuts

**Ctrl + K** → generate / edit code with AI for the selected fragment

**Ctrl + L** → open the AI chat panel

**Ctrl + Enter** → execute a prompt in AI chat

**Ctrl + I** → inline AI edit (AI modifies code directly in place)

💡 **Most common workflow:**

1. select code
2. press **Ctrl + K**
3. type a command, e.g. `"refactor to async"`

---

## 🔎 Project Navigation

**Ctrl + P** → quick file open

**Ctrl + Shift + P** → command palette (all commands)

**Ctrl + Shift + O** → list of functions in the current file

**Ctrl + T** → search symbols in the project

---

## 🔍 Search

**Ctrl + F** → search in file

**Ctrl + H** → replace in file

**Ctrl + Shift + F** → search in entire project

**Ctrl + Shift + H** → replace in project

---

## ✏️ Code Editing

**Alt + ↑ / ↓** → move line

**Shift + Alt + ↓** → duplicate line

**Ctrl + /** → toggle comment

**Ctrl + D** → select next occurrence

**Ctrl + Shift + L** → select all occurrences

---

## ⚡ Multicursor

**Alt + Click** → add new cursor

**Ctrl + Alt + ↑ / ↓** → cursors across multiple lines

---

## 📂 File Management

**Ctrl + N** → new file

**Ctrl + W** → close file

**Ctrl + Tab** → switch between files

---

## 🔎 Code Navigation

**F12** → go to definition

**Alt + F12** → peek definition

**Shift + F12** → find references

**Ctrl + Click** → go to definition
